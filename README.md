# 《语音信号处理》大作业 Track 2：低码率语音编解码

本仓库提供可运行的神经编解码基线。请先阅读 [赛题说明](大作业%20track%202.md)，再按 [平台使用与复现指南](COURSE_GUIDE.md) 挂载自己的语料、选择 GPU 并设置可写输出目录。数据路径和 GPU 编号不固定，不需要修改源码。

## 基线方法

模型处理单通道 16 kHz 时域波形：因果卷积编码器 → 三层残差矢量量化（RVQ）→ 因果卷积解码器。每 160 个采样点传输 3 个 8-bit 索引，即 10 ms 一帧、24 bit/帧、固定 2.4 kbps。每个输出 `.bin` 都有同名 `.json` 保存原始长度；解码只需要这两种文件与模型权重。

| 项目 | 配置 |
|---|---:|
| 采样率 | 16 kHz |
| 帧长、帧率 | 160 samples、100 帧/秒 |
| 量化器 | 3 层 × 256 码字 |
| 编码器步幅 | `2 × 4 × 4 × 5 = 160` |
| 解码器步幅 | `5 × 4 × 4 × 2 = 160` |
| 编码前视 | 无；结构采用因果卷积 |

训练使用时域 L1、三种分辨率的频谱损失、RVQ commitment、对抗损失与特征匹配损失。对抗训练在 10,000 步重建预热后渐进启用。`best.pt` 按验证重建损失选择。

## 从哪里开始

1. 在平台上挂载 VCTK 0.92 与 LibriTTS，选择 GPU 和可写工作区；设置 `VCTK_ROOT`、`LIBRITTS_ROOT`、`GPU_ID`、`WORK_ROOT`。
2. 按 [指南](COURSE_GUIDE.md) 安装依赖、生成清单、训练，再对固定 200 条公开验证语音编码、解码和评分。
3. 与 [参考成绩](BASELINE_RESULTS.md) 比较；盲测发布后只替换输入挂载路径并运行推理与格式检查。

仓库包含一份参考 `best.pt`，可用于验证接口；从头训练后的权重保存在你指定的 `WORK_ROOT`。原始语料、个人挂载路径下的数据以及后期盲测内容不随仓库发布。
